# ASR 领域词表（hotwords）：一行一个词，# 起注释
#
# 用途：给解码器一个"这段视频大概会说什么"的偏置，专治同音专名（见 docs/DECISIONS.md D26/D36）。
#
# 收录标准（收紧后）：**每一条都必须对应一次真实实测的错例**。
# 早先还写过"通用高频易错词"（认知/情绪价值/底层逻辑…），但那些是凭常识加的、
# 零实测支持；而词表整体在实测里是**有害**的（0.0433→0.0751，漏字 11→56，见 D26），
# 所以未经验证的词只会增加噪声——本次已全部删除。要加词请附上"哪支视频、错成什么"。

# —— 实测错例（男性是最好的血包，抖音 259.77s）的正确写法 ——
血包                     # ASR 听成"雪包"
供血                     # ASR 听成"工学"（"持续供血的血包"）
经济价值                 # ASR 听成"经营价值"（与"情绪价值"对举）
衣不蔽体                 # ASR 听成"一不避体"
断气                     # ASR 听成"断亲"（"我爸断气的那一刻"）
娘俩                     # ASR 听成"两俩"
享福                     # ASR 听成"想福"
干瘪                     # ASR 听成"干"（"一具干瘪的皮囊"）
干瘪的皮囊               # 同上，整词偏置更稳
从小到大                 # ASR 听成"创造了"（"我从小到大的努力"）
