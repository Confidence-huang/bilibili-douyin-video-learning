```markdown

## 基本信息
| 字段 | 内容 |
|------|------|
| 链接 | {URL} |
| UP 主 | {uploader} |
| 时长 | {duration} |

## 一句话总结
{summary}

## 5 个要点
1. ...
2. ...
3. ...
4. ...
5. ...

## 适合人群
- ...

## 值得看吗？
{verdict — 1-2 sentences}
```

## Single Video Summary (Standard)

The default template shown in SKILL.md — 基本信息, 一句话总结, 适合人群, 前置知识, 3分钟速读, 详细笔记(时间轴), 核心概念, 操作步骤, 重要结论, 易错点, 复习题, Anki卡片, 待确认.
