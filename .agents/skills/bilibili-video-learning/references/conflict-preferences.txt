# 冲突裁决表（每行：错误写法→正确写法）——只用于融合时裁决"哪一侧的写法对"
#
# 为什么需要它：融合此前**永远信主源**，于是主源（硬字幕 OCR）自己的错字（如"赠/赡"）
# 会被继承；而如果反过来永远信次源，又会丢掉主源在大量同音字上比 ASR 更准的优势。
# 实测两类错误机制不同：
#   - 硬字幕是作者原文，**同音字**上比 ASR 准（血包/雪包、断气/断亲、衣不蔽体/一不避体…）；
#   - 但 OCR 会**形近字**认错（赡/赠），这类反而是 ASR 对。
# 所以用一张"已验证的错→对"表做第三判据：**哪一侧含正确写法就用哪一侧**，并记录依据。
#
# 收录标准：每一条都必须在 docs/DECISIONS.md D21 的交叉校验里被人工确认过。
# 维护提示：这是**裁决**用表，不影响解码；领域词表（asr-lexicon.txt）是**解码偏置**用表，两者用途不同。

# —— 硬字幕（作者原文）正确、ASR 同音误听的 ——
雪包→血包                # 硬字幕；全片标题也写作"血包"
工学→供血                # 硬字幕（"持续供血的血包"）
创造了的努力→从小到大的努力  # 逐帧放大核对
断亲→断气                # 硬字幕（"我爸断气的那一刻"）
两俩→娘俩                # 硬字幕（"把我们娘俩丢在世上"）
想福→享福                # 硬字幕
一不避体→衣不蔽体          # 硬字幕
经营价值→经济价值          # 硬字幕（与"情绪价值"对举）
干瘪的皮囊→干瘪的皮囊       # 占位：OCR 曾把"瘪"认成"干"，正确写法已在两处出现
